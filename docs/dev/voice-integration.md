# Spanish voice generation

`tools/voice_clone.py` renders supplied text with Chatterbox Multilingual V2, a user-supplied local voice reference, and the mono underwater effect. The renderer requires a 20-second, mono, 24 kHz PCM16 WAV supplied with `--reference`. No podcast excerpt or other voice-reference source file is included in the repository. Users must provide their own local reference and confirm they have applicable rights and consent for voice cloning in their jurisdiction. The three C-derived game voice clips are authorized for publication; the private reference excerpt is not.

Outputs are WAV at 24 kHz. Model output can vary between runs; cached model weights are downloaded by Chatterbox and are not stored in this repository. Existing placeholder files cannot be regenerated byte-for-byte without their original cached model output.

## Setup and rendering

Use Python 3.12 and create an environment. The recipe versions for Chatterbox, PyTorch, torchaudio, NumPy, SciPy, SoundFile, and librosa match the versions present in the development environment used to exercise this tool. This is not a claim that a fresh pip installation has been verified. PyTorch wheels vary by platform; install the matching PyTorch 2.6.0/torchaudio 2.6.0 wheel for CPU or Apple Silicon first, then install the recipe:

```sh
python3 -m venv .venv-voice
. .venv-voice/bin/activate
python -m pip install --upgrade pip
# Install torch==2.6.0 and torchaudio==2.6.0 for your platform first.
python -m pip install -r voice/requirements-voice-clone.txt
python tools/voice_clone.py --reference /path/to/your/voice-reference.wav --text 'Qué... dónde estoy...' --output tmp/voice-candidates/new/line.wav
```

Use `--plan` to validate the supplied reference and inspect settings without loading or downloading model weights:

```sh
python tools/voice_clone.py --reference /path/to/your/voice-reference.wav --text 'Espera... ¿quién soy?' --output tmp/voice-candidates/new/line.wav --plan
```

The CLI validates the WAV format and duration before model loading, and refuses to overwrite an existing output. It uses Chatterbox `language_id=es`, exaggeration `0.55`, CFG weight `0.30`, temperature `0.70`; the model generates mono speech, which receives a fixed mono underwater treatment. No moving stereo/panning effect is applied. The renderer does not apply the wrapper's silence trimming, edge fade, or fixed-gain loudness normalization; it fails before writing if processed samples exceed full scale. Synthesis is not deterministic, and first use downloads the published model into Chatterbox's normal external cache. Generated files are fresh model renders, not byte-identical preserved stems; this generic renderer does not prefix-splice audio.

## Current event dialogue

When replacing the existing placeholder dialogue assets, the first three event lines are:

1. `¿Qué...? ¿Dónde estoy?`
2. `Las luces... las luces de emergencia... el interruptor está a la derecha de la puerta.`
3. `La energía secundaria está en la última puerta a la izquierda.`

Line 4 (`¿Cómo sabía eso? Espera... ¿quién soy?`) is intentionally excluded from that replacement list. The CLI accepts arbitrary new text, so additional future dialogue does not require a fixed event map. The three C-derived clips at `assets/audio/voice/hesitant-tail-c-line-{1,2,3}.wav` are installed and played by the game, and are authorized for publication. Keep the private source reference outside version control. The `.gitignore` rule excludes the local `voice/source/C-reference-20s.wav` path so `git add .` does not include it.
